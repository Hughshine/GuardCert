# 有符号片段根的二维分块

这一阶段将 signed 窗口路线的外两轴分块接入同一个统一编译入口。根游标可以为负数；内层仍由实际源 AST 重置为零。442 个适配模块、七个 lowering 模块、三个核心模块和 592 个证明源码哈希的全量编译与审计已通过，保持既有 7、12、42 项假设。17 种配置完成 10438 次完整汇编调用；11 组独立分支诊断及旧非负起点入口的定向回归也已通过。

## 分块对应与检查

`window_tiled_loop` 从 `floor(root_lower / rows)` 开始枚举行块，行块上界为 `ceil(n / rows)`。下界是编译时常量，运行时取整除法的分子 `n+rows-1` 保持非负。候选点上的 guard 使用真实根入口快照，只执行源 `[start,n)` 中的行，以及源 `[0,m)` 中的列。

例如 `start=-2,n=3,m=2`、声明根下界 `-16` 和块大小 `17×13`：行块从 `-1` 开始，第一块只保留行 `-2,-1`，下一块保留行 `0,1,2`。列块保留列 `0,1`。候选执行后恢复公共游标 `i=3,j=2`。其余入口前提由 signed 窗口检查建立，条件失败执行源片段。

`window_guarded_tile_range` 证明去掉上界之外的块不会改变事件列表。`window_tile_trimming` 将原始行块范围缩短到上述有效上界。`checked_window_tiling_correct` 复用实际源的 bounded tiling validator：坐标对应和依赖合法性仍由候选证书检查。`check_window_tiled_package_sound` 把验证结果、实际机器 lowering 和源公共出口恢复组合为 Clight 片段契约。

统一入口接受：

```text
(interval (per-axis (tile 2 3)))
(interval (per-axis (tile 17 13)))
```

原生提案器只提交 `1..2147483647` 中的块大小。数学上的正块大小还要通过已验证的机器表达式和 private temporary 检查；不能安全编码的候选拒绝变换。提案器不受信任，正确性定理对任意提案器成立。这个原生范围限制避免将明显不适合 signed32 表示的数送入昂贵检查，不构成一般编译时间上界。窗口范围和实际访问权限沿用源对应证明。当前快路仍只支持一个真实指针，不组合运行时版本族。

## 验证与证据边界

新测试复用 signed 窗口阶段的八个内核、614 个输入、完整缓冲区和公共游标模型，加入两个正块大小、零块大小、负块大小及不能直接表示的块大小。17 种配置均通过实际 CompCert 汇编执行，共 10438 次调用。编译器 SHA256 为 `a9e10f93b765d08c1fbdbee9b390553551bbdd991ab84ee5c8f34ce4683d2edc`，每次运行核对全部证明与原生源码哈希。全量审计日志为 `build/window-tiling-full-proof-audit.log`，验证进度为 `build/window-tiling-validation-pipeline-report.json`。

11 组实际 guard 分支诊断通过 4010 次调用，1770 次执行候选、2240 次回退，共观察 3472 个候选片段入口。其中负根、负参数和负下标快路入口分别为 722、2232、1852，类别可以重叠。实际参数范围测试 19280 次，44 个未定义参数入口均执行零次参数测试。单指针静态分离路线仍执行零次指针比较。分支诊断使用 GCC 执行插桩 Clight，完整汇编执行由独立套件报告。

上一阶段保留的全部 12 组 signed 汇编配置和九组分支配置逐行完全相同，包含片段、范围、逐入口决定、查询计数及代码大小；旧 unsupported-tile 配置被新的两条接受及三条拒绝配置取代。三组旧非负起点入口汇编配置和对应两组分支诊断也逐行完全相同；其完整八组历史回归保留在上一快照，不能将定向回归计为八组重跑。

此前不含原生范围筛选的中间编译器在两条正块大小及零、负块大小上完成了执行检查，但超大正数提案处理过慢，测试被中断。日志与中间二进制保存于 `build/window-tiling-before-width-filter/`；它不是完整通过的阶段结果。加入筛选后重新提取编译器并重跑全部配置，避免将不同二进制的报告混用。
