# 真实 C 下标的仿射编码

新的源前端允许复制的读写下标分别为两个循环变量上的仿射表达式，包括转置、列缩放、常数左乘和散布写入。它不要求读写共享某个 `i * stride + j` 模板。例如：

```c
for (; i < n; ++i) {
  k = 2 * i + m - p;
  for (j = 0; j < k; ++j) {
    b[i * 20 + j] = a[j * 17 + i];
    c[i * 24 + j] = b[i * 20 + j];
    b[i * 20 + j] = b[i * 20 + j] + (i * 11 + j + 19);
  }
}
```

复制可以与已有布局操作在同一列表组合。当前 C 入口要求前端规范 `for` 结构；将递增写在 `while` 体末尾会安全拒绝，尚未证明该语法归一化。源域、实际读写指令、候选依赖检查、条件编码、候选机器 lowering 和完整 Csem→Asm 定理继续使用同一个统一入口；早先受支持的源族先由其既有解析器处理。

## 编码及语言实例

`memory_encode_index` 将源表达式编码为 `a*i+b*j+c`。它处理加减、任意嵌套的常数乘法和两个循环变量，保留源表达式的括号及左右乘形式。`memory_encode_index_value` 证明数学编码，`memory_encode_index_reads` 证明实际读取只来自所声明的两个变量；`memory_index_expression_evaluation` 将这些事实连接到真实 CompCert `Int` 求值。

`memory_affine_access_inverse` 和 `memory_affine_access_load_inverse` 用已证明的下标求值解码实际 Clight 地址及 load。`memory_affine_access_registry` 证明登记表中的访问单元与真实物理地址一致。数组对象的类型取自其实际长度，访问的仿射系数另行携带；相同对象的多个访问保持同一标识，依赖验证因此能看到它们的冲突。

`memory_affine_copy_inverse`、`memory_affine_copy_registry_point` 以及 `memory_general_sequence_point_execution` 将赋值和整个混合列表接到具体内存指令。`memory_general_layout_body_model` 实例化通用源体接口的全部语义字段。源解析器随后检查完整 AST、变量区别、稳定参数、所有访问及对象覆盖证书，返回统一候选服务所消费的证明包。

## 范围及条件

当前接受的访问要求聚合后的常数项为零、行列系数非负，并通过静态有限公共域的独立范围检查。原始表达式可以含加减和负常数，只要编码结果满足这些要求。检查器证明该公共域中每个实际下标都落在各自对象的长度范围内。

域建议是保守的：对 `a*i+j` 这样的规范行访问，保留对象长度和行步长，限制行宽避免相邻行覆盖；其余仿射访问提出有限方形域，边长由对象长度和系数得到，并设 1,024 的提议上限。各访问与已有操作的域取公共范围。建议本身不是证明，最终访问检查另行核对。实际源上界和参数仍经既有安全运行时条件检查，候选仍由独立域及依赖证书决定是否接受。既有外层次数条件搜索可以进一步缩小接受域。

零常数项使首个实际执行点访问对象的基址，提供新插入的基址比较所需地址有效性。这一义务不能仅由“类型是数组”代替。非零偏移、读取稳定标量参数的下标、一般指针切片、不同布局的多读取算术、任意多层 C 仿射域仍未由这一路线覆盖。

## 运行验证

复现目标为 `make native-memory-affine-access`，输入是 [实际 C 程序](../examples/native_memory_affine_access.c)。独立模型按源次序执行全部读写并核对完整数组及公开计数器；GCC 参考输出已与模型核对一致，共 3,489 行。15 组配置通过完整 C→Asm 编译与执行：五种调度、四组分块、三种无效候选、资源耗尽、错误证书和未支持的 `while` 结构。五组分支诊断分别确认七个受支持函数的真实快路、零次循环与非零起点回退，外围重复循环确认两次快路。诊断执行的是经过修复打印格式并插桩的 Clight 文本；证明编译器产生的汇编另行检查。


同数组转置读写在交换以及非平凡分块时得到 `n <= 1` 的条件；identity、分裂、平移、剪切和 1×1 分块保持更大范围。散布写入在交换与 17×13 分块时得到 `n <= 8`，另有候选保持 `n <= 20`。这些区间是保守的充分条件。独立源执行模型在 `n=6,m=6,p=0` 为无条件同数组转置交换找到 11 个不同单元，为 2×3、4×4 分块各找到一个不同单元；未给分裂或 17×13 分块报告未找到的反例。

当前全量审计编译 141 个适配模块和七个 lowering 模块，物理非别名证明闭合，指令桥继承七项假设，validator 继承 12 项，统一编译器精确继承 CompCert 与 validator 的 42 项并集。没有新增全局公理。验证二进制 SHA-256 为 `36ade895ce65940bd90560a882ecf2e0d4730594e9ed850117609deaf16dc50b`，详细结果为 `build/native-memory-affine-access/{report,branch-report}.json`。
