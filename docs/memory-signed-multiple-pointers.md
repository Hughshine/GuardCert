# 有符号窗口中的多指针变换

这一阶段把带负起点和负地址参数的规范矩形循环推广到多个稳定 `int *`。单指针仍使用窗口内单元分离的静态证明；多个指针使用实际源足迹上的完整交叉扫描。mapped 候选、仿射调度生成和外两轴分块共享同一个区域契约及完整 Csem→Asm 端点。

正式源码已通过干净全量 Rocq 编译和假设审计：461 个适配器模块、7 个 lowering 模块和 3 个核心模块，记录 611 份证明源码哈希。完整程序定理的假设精确保持上一阶段 CompCert 与 validator 的原有并集 42 项，没有新增公理。提取后新路线的完整原生套件、分支诊断和已有路线回归均通过。

## 使用方式

源程序可以包含以下片段及调用方代码：

```c
for (; i < n; ++i)
  for (j = 0; j < m; ++j)
    p[16*i+j+u] = q[16*i+j+v] * alpha + beta*i+j;
```

`i` 的真实入口值可以为负数，`u` 和 `v` 是片段内稳定的 signed32 地址参数。`p`、`q` 可以指向不同数组，也可以是同一数组的切片。运行时先检查入口活动性、根范围、各轴正上界和参数区间，再检查该片段实际使用的跨指针单元。`p != q` 不能代替这一检查：例如 `q=p+1` 仍可能产生重叠。

已有统一提案形式无需变化：

```text
(interval (per-axis (schedule ((coordinate 1) (coordinate 0) ordinal) ((swap 0)))))
(interval (per-axis (tile 2 3)))
```

提案器提供候选，不是正确性证书的信任边界。源识别、窗口范围、坐标对应、真实依赖和机器 lowering 都经过独立检查。不能验证的提案保留源；已插入检查在当前输入上拒绝时，也执行完整源片段。候选退出恢复源公开循环游标。

## 它提供的证明

`window_footprint_member` 将参数固定后的实际 `[start,upper)` 坐标与源使用的逻辑单元对应。`window_source_runtime_domain` 从正常源执行获得实际访问权限、对齐和条件定义性，不要求源未使用的窗口单元具有权限，也不把逻辑窗口视为分配长度。

`window_axis_pairs_execution` 证明私有坐标循环执行实际地址比较，并得到数学上完整访问对检查的布尔结果。负逻辑下标由已证明的机器表达式求值和实际地址能力连接到 CompCert 指针语义。`window_axis_pointer_pairs_separation` 在接受时建立受限实际足迹的 NonAlias。

`window_axis_guard_execution` 组合短路头部与扫描，证明检查有定义、保持公共 temporary 和内存，并在接受后的状态建立候选前提。空源和未定义地址参数先被头部拒绝，不执行地址扫描。检查可以更新新鲜私有坐标和标志；`window_projected_candidate_rule` 使用同一有状态框架处理接受和回退，不要求这些私有值回到原值。

`check_window_axis_mapped_package_sound`、`check_window_axis_scheduled_package_sound` 和 `check_window_axis_tiled_package_sound` 消费实际源与候选、依赖证书、lowering 和出口恢复。`check_memory_window_proposal_sound` 在单指针静态路线与多指针扫描路线之间选择。最后由统一编译器的 `compile_memory_unified_regions_correct` 接到完整 Csem→Asm 保证。

## 范围和成本

根上界仍要求为正数，内层源循环由 AST 重置为零；各轴上界和 signed 参数区间采用已验证的有限 profile 搜索。最多提交 32 条原始访问，保留重复访问对。若活动点数为 `P`，当前交叉扫描是 `O(A²P²)`；发现重叠后仍完成扫描，未作提前停止。read-read 跨指针别名也保守拒绝。signed 路线尚未组合运行时版本族、廉价前缀或边界扫描策略；不保证接受范围最优或执行加速。

## 执行验证

测试源码包含六个内核和 690 个不同输入，比较两块完整 4096 单元缓冲区及公共游标。存储形态包括独立数组、同数组分离切片、相同基址和偏移为 1 或 16 的重叠切片；还包含负根、负地址参数、完整 signed32 RHS、超出所选区间及空指针零次循环。
