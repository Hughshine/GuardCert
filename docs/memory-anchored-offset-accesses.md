# 源访问建立的基址证据与邻居偏移

统一编译器的源体实例进一步允许非负常数偏移的仿射复制，例如：

```c
for (; i < n; ++i) {
  k = 2 * i + m - p;
  for (j = 0; j < k; ++j) {
    b[i * 20 + j] = b[i * 20 + j + 1];
  }
}
```

偏移参与真实访问函数，依赖验证器可以看到邻居关系。有限公共域检查独立证明每个下标落在各自对象长度内。候选、机器 lowering、运行时条件、公开计数器修复及完整程序宿主复用既有统一路径。

新增检查不能假定数组对象的零偏移地址在任意 CompCert 内存中都有效。这里从首个实际执行点的访问建立证据：任一读或写的零常数访问可以为该对象提供基址有效性，整个列表的所有对象请求必须被这些证据覆盖。同一对象的非零访问共享已建立的对象登记项；先前 store 的权限保持将证据向入口传递。

`memory_general_sequence_anchors` 收集提供零偏移证据的请求，`memory_general_anchors_registry` 从实际片段执行构造登记表。`memory_index_offset_box_sound` 证明包含非负常数项的范围检查；`memory_offset_sequence_point_execution` 组合真实赋值与内存指令；`memory_offset_layout_body_model` 实例化全部源体接口义务。`describe_memory_offset_region` 核对完整 AST、实际访问、稳定参数、范围及证据覆盖，随后交给同一候选服务。

因此，片段中的 `b[i*20+j] = a[i*31+j+1]` 在没有其他 `a[0]` 证据时被拒绝。若另一个实际执行的读取访问 `a[j*17+i]`，则可以为 `a` 提供所需证据。常数为负的访问和非仿射下标也被拒绝。当前仍要求两层规范 C `for`、零起点快路和非负聚合系数；一般指针切片、更深的 C 仿射域及一般多读取算术继续推进。

复现目标为 `make native-memory-offset-access`，输入为 [实际 C 测试](../examples/native_memory_offset_access.c)。独立模型与 GCC 已核对 3,651 行完整数组及公开计数器输出；14 组配置的完整汇编结果均与它们一致。五种调度、四组分块、三种无效候选、资源耗尽和错误证书均经实际编译与执行；缺少证据、负常数及非仿射访问保留原片段。


交换和非平凡分块将同数组转置邻居读取及散布写入的次数条件收紧为 `n <= 1`；前向邻居复制和有证据覆盖的混合链保持更大范围。分裂在四个受支持函数上接受，在两个混合链上拒绝。独立反例 `n=1,m=2,p=0` 中，源执行的 `b[0]` 为 7，无保护分裂后为 52；仅缩小外层次数不足以接受这个候选。

五组 Clight 打印结果分支诊断核对全部六个受支持函数的接受或回退，验证正条件、零次循环、非零起点及缩小次数域之外的实际选择；外围重复循环确认两次命中。分裂的两个链应回退，诊断将其计数核对为零。诊断单独执行插桩后的打印结果，已证明编译器的汇编另行检查。

本阶段全量审计覆盖 145 个适配模块和 7 个 lowering 模块，物理非别名闭合，指令桥继承七项假设，validator 继承 12 项，统一编译器精确继承原有 42 项并集。二进制 SHA-256 为 `90668e2ab9d3670d506aefec3b1bf35caf46437df0d065353ef419cd8e43f546`。该二进制还通过上一批仿射访问的 15 组配置与五组分支诊断回归；结果位于 `build/native-memory-offset-access/{report,branch-report}.json` 和对应回归目录。
