深层多指针服务也可验证重复累加，不要求每个迭代点都写不同的输出单元。实际例子为三层非矩形矩阵内核：

```c
for (; i < n; ++i) {
  K = i + m;
  for (j = 0; j < K; ++j) {
    L = p;
    for (k = 0; k < L; ++k)
      a[32*i+j] = a[32*i+j] + b[32*i+k] * c[32*k+j];
  }
}
```

输出 `a[32*i+j]` 在多个 `k` 点反复读写。外部工具提议 `i-k-j` 顺序，保留原域与所有具体指令；坐标恢复证据为 `(swap 1)`。检查器必须确认同一输出单元的依赖仍保持，而非把所有点当作独立操作。

`scripts/affine_inner_interchange_candidate.py` 从实际三层请求构造有限盒、原域测试及具体参数重排。候选算法不受信任，仍经域、指令、依赖、机器 lowering 和源派生 guard 检查。这一例子使用已有证明与统一 Csem→Asm 入口，没有添加专用内存交换公理。

`inner-interchange-parametric` 保留参数化循环头，机械地把每个上界与叶子变量重新绑定到 `i-k-j` 环境。它不枚举静态盒；若某个上界需要本位置尚未引入的轴，产生器不提议这一直接交换。接受仍由原检查器决定，产生器的语法检测不构成正确性证据。

十四种配置共运行 **672 次实际 CompCert 汇编调用**：禁止候选、恒等、盒式内层交换、参数化内层交换、交换后 `2×3` 分块、交换后分块并完整分区，参数化交换后分块、其完整分区，以及错误第一段、错误分块 witness、错误参数化 witness、依赖外层的分块循环头、缺少坐标恢复映射和验证器资源限制。比较所有三个 2,048 单元数组和五个公开控制出口。七种合法候选安装；六种错误、尚不支持的循环头／资源配置保留源。

分块组合提交 `(chain inner-interchange (tile-box 2 3 permuted-axes))`；每段各自通过检查，再返回原源到最终候选的证书。这里分块的是交换后的 `i,k` 轴。完整分区配置另使用 `partition-target`，不改变各点的源操作。独立模型也按 `(floor(i/2),floor(k/3),i,k,j)` 排序，核对分离访问的行为，并记录忽略别名时的不等反例。

参数化分块提案使用实际循环上界，并在进入各点循环前排除空块。它沿用已有分块证据与机器 lowering；块上界是保守的仿射界，不引入运行时除法，也不保证最紧的块数。当前产生器要求前两轴的循环头相互独立：本例先交换为 `i-k-j` 再分块 `i,k`；直接分块原来的 `i,j` 会因 `j < i+m` 被产生器拒绝，保留源。错误 witness 仍由独立检查器拒绝。

独立 Word 模型保留乘法和累加的 signed32 回绕；检查前提仅限制控制与地址运算，不要求数据乘加没有回绕。模型还在 `(mode,start,n,m,p)=(1,0,3,2,3)` 给出指针别名时直接交换内层顺序的完整数组反例。

实际 Clight 的单独分支诊断运行 **336 次**，在七种合法配置中各观察 **6 次候选、42 次回退**。诊断覆盖同块但实际访问不相交的快路径、数值条件成立而访问重叠的回退、负根入口和空循环。GCC 插桩只作为路径证据，实际汇编结果另行保存。

`make native-affine-nest-accumulation` 可复现。这里只证明行为保持和检查确实被执行，没有矩阵性能加速结论，也没有允许任意累加重排：例如改变同一输出单元的读取依赖仍须由验证器接受。
