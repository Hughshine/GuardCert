# 使用私有状态的循环式地址检查

本文记录逐元素双指针扫描及其第一版验证。后续[一般一维仿射地址扫描](memory-affine-alias-scans.md)已接入非单位步长、递减／常量下标、多指针和语言无关的有状态核心；下面的历史范围与编译器哈希保留为该版本的证据。

有限地址检查器会将潜在访问逐项展开到 Clight 中，因此设置了 64 项的资源限制。新的检查路径用两个私有计数器和一个累计标志执行地址扫描，检查代码的大小不随运行时循环次数增长。第一版针对一个计数轴、恰好两个实际参与访问的 `int *` 标识符，以及下标编码为 `i` 的访问；其他源形状继续使用现有检查路径。

例如：

```c
for (; i<n; i++) p[i] = q[i]*alpha + beta;
```

源包先核对完整循环、实际赋值、数组下标、稳定参数和逻辑范围。运行时检查先要求 `i=0` 和 `0<n<=cap`；通过后，用私有 `x,y` 查询所有 `&p[x]` 与 `&q[y]`，其中 `0<=x,y<n`。任一对地址相等会清除累计标志。扫描完成后，标志为真才执行已验证的候选，否则执行原循环。

比较不读取源数组中的数据。原循环的成功执行证明提供每个被查询地址的 `Mem.valid_pointer` 和 Mint32 对齐性质，因而检查不需要假设指针覆盖整个逻辑窗口。Mint32 地址不等和对齐推出实际四字节范围不重叠。同一个逻辑指针内不同下标的分离已有闭合证明，运行时只比较两个不同指针之间的访问。指针可以指向同一个 CompCert 内存块中的不同切片。

源中可以有多个赋值位置，读取自身或另一指针，使用稳定的 RHS 整数参数，以及机器整数加、减、乘。第一版检查下标的仿射编码是否为 `([1],0)`，不局限于某一固定 AST 拼写。外部候选仍需通过独立的域、访问与顺序检查；检查失败时编译器保留源程序。运行时 alias 检查失败则进入生成代码中的原循环分支。

## 证明接口

`memory_projected_private_rule` 将候选需要的前提与检查代码分开。语言实例提供：

- `projected_rule_domain`：检查安全执行所需的入口性质；由成功的源执行推出。
- `projected_rule_presumption`：候选正确性需要的语义前提。
- `projected_rule_local`：在该前提下，候选保持源执行结果、公共临时变量和内存等价。
- 源语句修改的临时变量集合及其证明。

检查编码器证明 `memory_projected_check_execution`：检查静默终止、返回接受或拒绝、保持内存，并保持指定公共临时变量。接受时，还需证明**检查后的状态**满足 `projected_rule_presumption`。私有计数器和标志可以改变，不需要恢复为入口值；入口甚至可以没有这些私有变量的绑定。

`memory_projected_private_rule_sound` 将这些证明组合成已有的 `projected_region_contract`。这个契约由统一的片段替换宿主接入 `compile_memory_unified_regions_correct`，继续给出完整 Csem→Asm 正确性。原来的纯决策树规则通过 `memory_private_rule_projected_check_sound` 接入相同接口。

具体实例的前提为合法计数范围，以及**源程序实际访问足迹**的受限位置映射满足 `NonAlias`。`memory_multi_pointer_projected_candidate_rule` 在这个映射中调用已有候选验证器，再将候选执行还原为实际 CompCert 内存执行。它不依赖有限地址枚举器。

## 当前边界与复现

本路径支持一个计数轴、两个访问指针、逐元素访问，以及 mapped 或生成的仿射调度候选。当前逻辑窗口为 1024，超过窗口时回退；它不是分配长度假设。扫描执行 O(n²) 次比较，没有性能加速声明。一般仿射下标、多轴扫描、更多指针和更高效的区间检查尚未接入此路径。其他路径的有限枚举资源限制仍然存在。一维反向候选可通过显式的 `reflect` 坐标映射接入，见[反射证明与运行记录](memory-coordinate-reflection.md)。

`make native-memory-loop-alias` 构建提取编译器，运行完整汇编回归和独立分支诊断。输入为 `examples/native_memory_loop_alias.c`，报告写入 `build/native-memory-loop-alias/`。测试包含大于旧 cap 的范围、窗口边界与超界、同址和部分重叠切片、同一块内不重叠切片、极端 RHS 整数，以及空循环中的未初始化指针和标量。汇编结果比较完整数组和公开计数器；分支诊断通过 GCC 执行加标记的 Clight 打印结果。
